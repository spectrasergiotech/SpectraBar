# SpectraBar

### Your System. Your Style. Your Control.

**More than a system monitor. A customizable floating control center for your Windows desktop.**

SpectraBar is a modern, lightweight floating desktop bar built with Rust. It combines real-time system monitoring, audio visualization, customizable shortcuts, and a beautiful interface in one compact experience.

## 📥 Download

**[⬇️ Download SpectraBar v1.0.0 for Windows](https://github.com/spectrasergiotech/SpectraBar/releases/latest)**

Windows 10 / Windows 11

## ✨ Features

### 📊 Real-Time System Monitoring
- CPU usage
- RAM usage
- Disk activity and storage
- Network upload and download speeds
- GPU monitoring
- Available CPU and GPU temperature and power sensors

### 🎵 Audio Visualizer
Four visualization styles:
- Bars
- Bars with Caps
- Oscilloscope
- Dots

Customize colors and sensitivity to match your desktop.

### 🎨 Deep Customization
- 8 built-in themes
- Custom colors and gradients
- Horizontal and vertical layouts
- Adjustable transparency
- Custom dimensions and spacing
- Rounded corners, borders and shadows
- Automatic sensor value colors

### 🚀 Desktop Productivity
- Custom application shortcuts
- Folder shortcuts
- Drag-and-drop support
- Always-on-top mode
- Customizable clock and date
- Windows startup integration
- System tray support

### ⚙️ Smart Configuration
- Automatic settings persistence
- Backup and restore settings
- Factory reset
- Custom sensor groups

### 🌎 Multilingual Interface
- English
- Português
- Español
- 中文

## 🖥️ Requirements
- Windows 10 or Windows 11
- Compatible hardware for available sensor readings
- Compatible audio device for audio visualization

Some hardware metrics depend on device and sensor availability.
