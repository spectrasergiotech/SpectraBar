
# SpectraBar

### Your System. Your Style. Your Control.

**More than a system monitor. A customizable floating control center for your Windows desktop.**

SpectraBar is a modern, lightweight floating desktop bar built with Rust. It brings real-time system monitoring, audio visualization, customizable shortcuts, and a beautiful interface together in one compact experience.

Designed to stay out of your way while keeping everything important within reach.

---

## ✨ Features

### 📊 Real-Time System Monitoring
Keep an eye on your hardware performance with customizable monitoring modules:

- CPU usage and performance graphs
- RAM usage
- Disk storage and activity
- Network upload and download speeds
- GPU usage
- CPU and GPU temperatures
- CPU and GPU power consumption

### 🎵 Audio Visualizer
Bring your desktop to life with a real-time audio spectrum visualizer.

Choose between four visualization styles:

- **Bars** — Classic spectrum bars
- **Bars with Caps** — Animated bars with illuminated caps
- **Oscilloscope** — Smooth waveform visualization
- **Dots** — Minimalist dot-based visualization

Customize colors and sensitivity to match your setup.

### 🎨 Deep Customization
Make SpectraBar yours.

- 8 built-in themes
- Custom colors and gradients
- Horizontal and vertical layouts
- Adjustable transparency
- Custom dimensions and spacing
- Rounded corners and shadows
- Custom borders and separators
- Automatic sensor value colors
- Multiple icon styles

**Built-in themes:**
Cyberpunk 2077, Synthwave, Matrix, Nord, Ocean, Mac OS, Dracula, and Solarized Light.

### 🚀 Desktop Productivity
More than just monitoring.

- Custom application shortcuts
- Folder shortcuts
- Drag-and-drop support
- Always-on-top mode
- Customizable clock
- Date and seconds display
- System tray integration
- Start with Windows

### ⚙️ Smart Configuration
- Automatic settings persistence
- Backup and restore settings
- Factory reset option
- Custom sensor groups
- Independent horizontal and vertical layout settings

### 🌎 Multilingual Interface
Available in four languages:

- English
- Português
- Español
- 中文 (Chinese)

## 🛠️ Built With

SpectraBar is powered by:

- **Rust** — Core application
- **egui / eframe** — Graphical user interface
- **LibreHardwareMonitor** — Hardware sensor monitoring
- **CPAL** — Audio device access
- **RustFFT** — Real-time audio spectrum analysis
- **Serde** — Configuration serialization

---

## 💻 Requirements

- Windows 10 or Windows 11
- A compatible audio output device for audio visualization
- LibreHardwareMonitor for hardware sensor readings

Some hardware metrics may depend on device compatibility and sensor availability.
